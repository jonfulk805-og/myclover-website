🚀 Quick Start

Up and Running in 5 Minutes

SSH into your CloverOS box, pull a model, and start chatting. That's it.

Start Chappie

SSH into your box and run:

sudo cloverstack-ctl start chappie

Pull a Model

Download your first AI model:

ollama pull llama3.2:3b

Open the UI

In your browser, go to:

http://<ip>:8083

Create Account

Click Sign Up, create your account. First account = admin.

Select Model

Use the model picker dropdown at the top of the chat window.

Start Chatting

Type your message and hit Enter. Fully private, fully local AI.

💡
Chappie is a default module — it's enabled automatically when you provision CloverOS. If it's not enabled, run sudo cloverstack-ctl enable chappie first.
🧠 Models

Add AI Models

Chappie uses Ollama to manage models. Pull any model from the Ollama library — it shows up in the chat UI automatically.

# See what's installed ollama list # Pull models ollama pull llama3.2:3b # 2 GB — great starter ollama pull llama3.1 # 4.7 GB — solid all-rounder ollama pull mistral # 4.1 GB — fast & capable ollama pull phi3 # 2.3 GB — lightweight ollama pull codellama # 3.8 GB — code-focused # Remove a model ollama rm <model-name> # Browse all models: https://ollama.com/library
💻 Hardware

Model Recommendations by Hardware

Pick the right model for your box. Bigger models = smarter responses but need more RAM.

🔌

Micro / GMKTek Mini

8–16 GB RAM — stick to models under 4B parameters.

phi3 gemma2:2b llama3.2:3b
🖥️

Edge / Desktop

32 GB RAM — solid general-purpose models.

llama3.1 mistral gemma2 codellama
🏗️

Rack / High-End

64 GB+ RAM or dedicated GPU — run the big models.

llama3.1:70b mixtral command-r
⚡
GPU acceleration: If your box has an NVIDIA GPU, Ollama automatically uses it. Check with ollama ps and nvidia-smi.

🔧 Advanced

Ollama Configuration

Tune Ollama's behavior — model storage, concurrency, and more.

# Edit Ollama config: sudo systemctl edit ollama # Add any of these under [Service]: Environment="OLLAMA_HOST=0.0.0.0" # Listen address Environment="OLLAMA_MODELS=/mnt/data/ollama" # Model storage Environment="OLLAMA_NUM_PARALLEL=2" # Concurrent requests Environment="OLLAMA_MAX_LOADED_MODELS=2" # Models in memory # Then reload & restart: sudo systemctl daemon-reload sudo systemctl restart ollama
🔌 API

Connect Apps to Chappie

Other CloverStack modules and CloverApps can use Chappie's AI via the Ollama REST API.

# API endpoint: http://localhost:11434 curl http://localhost:11434/api/generate -d '{ "model": "llama3.2:3b", "prompt": "Hello, Chappie!", "stream": false }' # From Docker containers, use: # http://host.docker.internal:11434
🔍 Troubleshooting

Common Issues

🔴 Chappie UI won't load (port 8083)

Check if the container is running: sudo docker ps | grep open-webui

If not running: sudo cloverstack-ctl start chappie

Check container logs: sudo docker logs open-webui

🔴 No models appear in the dropdown

Models must be pulled via ollama pull first. Run ollama list to check what's installed, then ollama pull llama3.2:3b to add one. Refresh the browser — models appear automatically.

🔴 Model is very slow

Check available RAM with free -h. The model should be smaller than your available RAM. Try a smaller model (phi3, gemma2:2b). If you have a GPU, verify Ollama detects it with ollama ps.

🔴 "Connection refused" or Ollama errors

Check Ollama: sudo systemctl status ollama

Restart: sudo systemctl restart ollama

Logs: sudo journalctl -u ollama --no-pager -n 50

🔴 Out of disk space

Check space: df -h — See model sizes: ollama list — Remove unneeded: ollama rm <model>

🔴 Reset Chappie (start fresh)

sudo cloverstack-ctl stop chappie && sudo docker rm open-webui && sudo cloverstack-ctl start chappie

⚠️ This removes chat history and user accounts. Models in Ollama are not affected.
