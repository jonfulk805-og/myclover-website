# Clover Lanes
Direction: premium after-dark bowling lounge. MyClover's metallic green, ruby and gold on black,
actual clover logo; wood and pins carry the color rather than floating UI effects.
Interface: league scoring strip first, turn indicator, then four shot controls and one primary action.
Menu: choose game, oil, finish and bumpers, then roll. Results retain the full scorecard.
Anchors: traditional Brunswick scoring grid (ten numeric cells plus total); contemporary bowling
lounge interiors (linear pendants, warm polished wood, dark ceiling). Deliberate deviation: a spare
practice mode uses the exact same physics and controls as scored games.
Tokens: #080d10 ground, #101a1e controls, #efbb62 metallic gold, #75d6ad clover highlight,
#f2f0e6 type, #acb8bb secondary. System-ui 11/12/14/18/35/70 scale; 8px base spacing;
5px control corners, no blur filters on WebGL. Desktop controls run horizontally, mobile 2x2.
